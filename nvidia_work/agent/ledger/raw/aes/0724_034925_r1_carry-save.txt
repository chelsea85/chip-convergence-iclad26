An elegant timing optimization can be achieved in `tlul_cmd_intg_chk.v` by isolating the complex integrity-checking logic from the late-arriving valid signal. By declaring explicit intermediate wires for the sliced fields and the error reduction logic, we prevent Yosys/ABC from performing sub-optimal technology mapping across logical boundaries, improving both slack and area.

### Ledger
- **Transform Applied**: `rtlscout-cutpoints` (timing-driven boundary isolation)
- **Exact Cone Touched**: `err_o` in `tlul_cmd_intg_chk.v`
- **Changed Signals**:
  - `chk_data_slice`: none -> 7-bit unsigned
  - `data_intg_slice`: none -> 7-bit unsigned
  - `data_slice`: none -> 32-bit unsigned
  - `valid_signal`: none -> 1-bit unsigned
  - `any_err`: none -> 1-bit unsigned
